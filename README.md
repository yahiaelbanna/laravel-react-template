# Rizuna T

## Introduction

An Intrnal system made for marketing company Wich face problems with follow up with clients and manage tasks and plans.

We'd Solve this problem by create a system that can help them to follow up with clients and manage tasks and plans, this system will handle:
- Marketing campaigns
- Content creation and publishing
- Social media management
- Customer relationship management
- Task management
- Plan management
- User management
- Role based access control
- Dashboard

And The Customer will have a mobile app to follow up with them.

## Features
- User Management
- Role Based Access Control
- Tasks Management
- Plans Management
- Customers Management
- Content Management
- Dashboard

## Technologies Used
- Laravel 12
- React 19
- TypeScript
- Tailwind CSS
- shadcn/ui
